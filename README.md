# BlackCat Tasks

Трекер задач для команды. В проекте доступны доска, список задач, поиск, фильтры и настройки полей. Задачи, пользователи и вложения хранятся в PostgreSQL.

## Локальный запуск

Понадобятся Node.js 22+ и запущенный PostgreSQL.

```sh
createdb blackcat_tasks
cp .env.example .env
npm ci
```

Укажите в `.env` подключение `DATABASE_URL`, email первого администратора и пароль длиной от 12 символов. Выполните:

```sh
npm run setup
npm start
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000) и войдите с указанными email и паролем. После создания администратора переменную `ADMIN_PASSWORD` можно убрать из `.env`. Для демо с двумя проектами и задачами запустите `npm run setup -- --demo`.

## Работа с задачами

- Администратор создаёт проекты и локальные учётные записи, приглашает участников по одноразовой ссылке и меняет роли в разделе «Команда». Личные профили доступны владельцу и администраторам. В разделе «Мои задачи» собраны задачи, назначенные пользователю во всех проектах.
- В администрировании есть отдельные настройки для полей проекта, общих полей задач и полей профилей. Поля появляются в существующих и новых карточках выбранной области. Доступны строка, длинный текст, число, дата, список и ссылка. Скрытие поля сохраняет введённые значения.
- В разделе «Статусы задач» администратор добавляет статусы, задаёт порядок колонок и отмечает статусы, которые считаются завершёнными. Статусы используются во всех проектах.
- Откройте задачу с доски или из списка. У каждой задачи отдельный адрес. На странице доступны заголовок, описание, тип, статус, приоритет, заказчик, исполнитель и поля проекта. В планировании можно указать категорию, целевую версию, родительскую задачу того же проекта, даты, оценку в часах и готовность. Создатель и время создания сохраняются автоматически.
- Прикрепляйте ссылки и файлы в карточке сохранённой задачи. Поддерживается до 20 вложений на задачу и до 10 МБ на файл. Изображения PNG, JPEG, WebP и GIF можно посмотреть в браузере.
- Из страницы задачи можно создать подзадачу в том же проекте или связать задачу с другой через «Связанные задачи». Доступны обычные связи, блокировки и дубликаты. Связь видна с обеих сторон.
- Для удаления задачи подтвердите действие в карточке. Вложения удаляются вместе с задачей.

Для командного доступа используйте общий адрес приложения и PostgreSQL. При запуске за HTTPS-прокси задайте `SECURE_COOKIES=1`.

## Проверка

Задайте `TEST_DATABASE_URL` с подключением к тестовой базе PostgreSQL и запустите `npm test`. Тест создаёт отдельную временную схему и удаляет её по завершении.
